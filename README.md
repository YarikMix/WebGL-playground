# WebGL-playground

Прототип главной страницы сервиса блокнотов (аналог Google Colab) в космической
стилистике. Репозиторий нужен, чтобы сравнить две реализации анимированного фона —
планеты и звёздного неба — без сторонних библиотек.

| Ветка | Фон | Демо |
|---|---|---|
| `main` | Canvas 2D + CSS-диск планеты | <https://yarikmix.github.io/WebGL-playground/> |
| `webgl` | WebGL, планета одним фрагментным шейдером | <https://yarikmix.github.io/WebGL-playground/webgl/> |

Всё, что отличает ветки, лежит в `sky.js` (и паре правил в `styles.css`):
`git diff main webgl -- sky.js`.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | разметка страницы |
| `styles.css` | токены, стекло, карточки, адаптив |
| `app.js` | данные-примеры, фильтры, поиск, переключатель анимации |
| `sky.js` | фон; контракт с `app.js` — `Sky.start(on)` и `Sky.set(on)` |

Сборки нет: открыть `index.html` в браузере или поднять любой статический сервер.

## Как устроен фон

В этой ветке весь фон рисует один фрагментный шейдер на полноэкранном треугольнике
(WebGL 1, без three.js и других библиотек, ~150 строк GLSL):

- планета — аналитическая сфера: нормаль восстанавливается из координат пикселя,
  поверхность и облака — 3D value-noise (fbm) по нормали, повёрнутой вокруг оси;
- облака: крупные системы задают, где облачно, мелкий fbm с искажением координат даёт волокна;
- терминатор: солнце стоит сразу за горизонтом, поэтому освещён только узкий серп у кромки,
  а под карточками — тёмная ночная сторона, и текст остаётся читаемым;
- ночные огни — точки в трёхмерной сетке, видимые только на суше и не под облаками;
- атмосфера — рассеяние к кромке изнутри и экспоненциальные ореолы снаружи;
- звёзды — хеш-сетка в полярных координатах вокруг центра планеты, метеор считается на CPU
  и приходит в шейдер одним `vec4`.

### Три варианта стекла карточек

Кнопки в подвале страницы переключают класс на `.page`, выбор запоминается:

| Режим | Как сделано | Цена |
|---|---|---|
| Имитация | заливка 4% белого + градиентный бордер через `mask-composite`, размытия нет | почти бесплатно |
| Blur | `backdrop-filter: blur(14px) saturate(140%)` — классический glassmorphism | браузер заново размывает область под каждой карточкой на каждом кадре анимации фона |
| Liquid glass | второй проход WebGL: сцена рендерится в текстуру, шейдер `GLASS` внутри прямоугольников карточек читает её со смещением | +1 проход; внутри стёкол 12 выборок текстуры на пиксель, на фаске 36 |

Как устроен Liquid glass: прямоугольники карточек берутся из DOM (`getBoundingClientRect`)
и уходят в шейдер uniform-массивом (до 16 штук; остальные карточки остаются в режиме
«Имитация»). Форма — SDF скруглённого прямоугольника. На фаске шириной 20px с круглым
профилем выборка фона уходит за край карточки — фон у кромки сжимается, как в линзе.
Красный и синий каналы смещаются на разную величину (хроматическая аберрация), середина
размывается спиралью из 12 выборок с поворотом, своим у каждого пикселя (зерно матового
стекла). Блик на кромке ярче с той стороны, где курсор. Сама DOM-карточка в этом режиме
прозрачна: от неё остаются текст и hover-свечение.

Канвас и карточки прокручиваются вместе, поэтому координаты стёкол пересчитываются только
при перестройке сетки (фильтр, поиск, resize), а не при скролле.

Если WebGL недоступен или шейдер не собрался, остаётся статичный CSS-фон из `main`.
Разрешение канваса ограничено 1.5× от CSS-пикселей: шейдер тяжелее Canvas 2D.

Общее для обеих версий: 30 кадров/с, пауза, когда канвас вне экрана или вкладка
в фоне, статичный кадр при `prefers-reduced-motion` и по кнопке «Анимация фона».
Геометрия планеты (центр и радиус) берётся из CSS-элемента `.limb`, поэтому фон
сам подстраивается под высоту hero и ширину окна.

## Деплой

`.github/workflows/pages.yml` на каждый push в `main` или `webgl` собирает сайт из
обеих веток и публикует его в GitHub Pages.
