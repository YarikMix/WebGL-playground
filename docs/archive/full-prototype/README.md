# Полная версия прототипа — архив

Снимки версии до урезания под РК 1. Код этой версии целиком лежит в ветке
[`archive/full-prototype`](https://github.com/YarikMix/WebGL-playground/tree/archive/full-prototype)
(коммит `d03fc33`); запустить: `git switch archive/full-prototype && bun install && bun run dev`.

Что было в этой версии и ушло из РК 1: поиск по блокнотам, квота GPU, рантаймы и ускорители
(статусы «Работает / Остановлен», T4/A100), фильтры «Все / Мои / Доступные мне / Работают»,
сортировка, загрузка `.ipynb`, чужие блокноты («от Ани К.»), «изменён …», запуск ячеек (▶ и `[ ]`).

| Файл | Что на кадре |
|---|---|
| `01-login.png` | Вход: логин и пароль, луна с приглашением создать аккаунт |
| `02-signup-errors.png` | Регистрация с ошибками валидации под полями |
| `03-list.png` | Список блокнотов целиком: шапка с поиском и квотой, hero, фильтры, карточки со статусами |
| `04-notebook.png` | Блокнот: шапка с метаданными, выбранная ячейка с кнопкой удаления, ячейки кода с ▶ |
| `05-notebook-empty.png` | Пустой блокнот после удаления всех ячеек |
| `06-list-375.png` | Список на 375px |
| `07-notebook-375.png` | Блокнот на 375px с тач-эмуляцией: полосы вставки у выбранной ячейки |

Десктопные кадры — окно 1280×900; `03-list.png` снят на всю высоту страницы (1265×1282 — ширина окна за вычетом полосы прокрутки). Мобильные — 375×812 при плотности 2×.
